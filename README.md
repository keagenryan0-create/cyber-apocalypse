# 🤖 Cyber Apocalypse - Robot Survival Game

A cyberpunk-themed bullet-hell survival game built with React and Canvas.

## 🎮 How to Play

**Controls:**
- **WASD** - Move your ship
- **SPACEBAR** - Shoot
- **Touch Screen** - Tap to shoot (mobile)

**Gameplay:**
- Dodge incoming enemies (red squares)
- Destroy them with your cyan laser bullets
- Collect green health pickups to restore health
- Defeat boss enemies (magenta) for extra challenge
- Gain weapon levels to increase firepower
- Survive as long as possible!

## 🚀 Play Online

[Play the game here!](https://keagenryan0-create.github.io/cyber-apocalypse/)

## 💻 Setup Locally

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## 🎨 Features

- ✅ Full survival gameplay mechanics
- ✅ Visual effects with shadows and glow
- ✅ Sound effects (laser & explosions)
- ✅ Boss fight system (10% spawn rate)
- ✅ Weapon leveling system
- ✅ Health/healing system
- ✅ Mobile-friendly controls
- ✅ Cyberpunk aesthetics with cyan/magenta theme
- ✅ Score tracking and leaderboard display

## 🛠 Technologies

- React 18
- HTML5 Canvas
- Tailwind CSS
